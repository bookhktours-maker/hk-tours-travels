A single-page site for your Puttaparthi cab/hotel/mini bus enquiry business. It's just one file (`index.html`), so it's free to host on GitHub Pages.

## 2. Put it on GitHub

1. Go to [github.com](https://github.com) and sign in (create a free account if you don't have one).
2. Click the **+** icon top right → **New repository**.
3. Name it something like `hk-tours-travels`. Keep it **Public**. Click **Create repository**.
4. On the new repo page, click **uploading an existing file**.
5. Drag in `index.html` (and this `README.md` if you like), then click **Commit changes**.

## 3. Turn on free hosting (GitHub Pages)

1. In your repo, go to **Settings** → **Pages** (left sidebar).
2. Under "Build and deployment" → **Source**, choose **Deploy from a branch**.
3. Branch: `main`, folder: `/ (root)`. Click **Save**.
4. Wait 1–2 minutes, then refresh — GitHub will show your live link, something like:
   `https://yourusername.github.io/hk-tours-travels/`

That link works immediately and costs nothing.

## 4. Getting found on Google when people search "tours and travels Puttaparthi"

A brand-new site won't outrank established ones overnight, but this will help over time:

- **Submit your site to Google Search Console** (free): [search.google.com/search-console](https://search.google.com/search-console) → add your GitHub Pages URL → verify → submit it for indexing. This is the single most useful step.
- **Set up a free Google Business Profile** for "HK Tours and Travels" listed in Puttaparthi — this is what actually shows up first for local searches like "tours and travels near me," often above regular websites.
- Once you have a custom domain (e.g. `hktoursandtravels.com`), you can point it at this same GitHub Pages site for free — ask if you'd like help with that later.
- Keep the phone/email in the page matching exactly what's on your Google Business Profile — consistency helps local search ranking.

## 5. Editing later

Any time you want to change text, add real packages, or swap in real photos of your cabs/hotels, just edit `index.html` directly in GitHub (click the file → pencil icon → edit → commit) — no coding tools needed for small text changes.
